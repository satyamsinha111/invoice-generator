# Quick Setup Guide

## 🚀 Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

This will install:
- Next.js 14 with App Router
- React 18
- TypeScript
- Tailwind CSS
- Puppeteer (for PDF generation)

### 2. Run Development Server
```bash
npm run dev
```

The app will be available at [http://localhost:3000](http://localhost:3000)

### 3. Start Creating Invoices!

That's it! No database setup, no auth configuration, no complex deployment. Just open your browser and start generating professional invoices.

## 📦 Build for Production

```bash
npm run build
npm start
```

## 🐛 Troubleshooting

**Issue**: PDF generation fails
**Solution**: Make sure Puppeteer installed correctly. Try:
```bash
npm install puppeteer --force
```

**Issue**: Styles not loading
**Solution**: Clear Next.js cache:
```bash
rm -rf .next
npm run dev
```
